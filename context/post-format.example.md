# Post format (example)

Copy to `context/post-format.md`. The house format for workflow-breakdown posts
on X. `content-routine` reproduces the full version inline; this file is the
skeleton so other skills can reference one source.

```
[HOOK: 3 lines, one job each]
L1  concrete metric or dollar figure + a promise large enough to stop the scroll
L2  what it looked like / what happened. no mechanism.
L3  the opinion that reframes what the reader just absorbed

[SETUP: 1-2 lines bridging hook to story]

[STEPS: numbered, one action per line; call out what happened BETWEEN steps]

[THE AGENT'S WORK: → bullets, one action each, include the questions it asked]

[THE OUTPUT: labelled by segment: "10 cold. …" "10 warm. …" "10 hot. …"]

[RESULTS: one figure per line, then the summary line]

[THE PATTERN: → bullets, 4-5, the repeatable system]

controversial take: [the insight most people will not act on]

comment [KEYWORD] for the workflow.
(follow for dm)
```

## Tone rules
- all lowercase for insight-series posts; sentence case for brand launches
- staccato. short. punchy.
- no em dashes, no emojis, no exclamation marks, no hashtags
- → arrows for system bullets
- numbers are specific and real ($12,847 not ~$13k, and never invented)
- observational, not selling; no filler ("basically", "actually")

## Self-check gate
- [ ] L1 has a specific figure
- [ ] entire post lowercase (or sentence case for brand), no em dashes
- [ ] → arrows present
- [ ] a labelled "controversial take:" section exists
- [ ] CTA uses one all-caps keyword + "(follow for dm)"
- [ ] the full workflow is NOT recoverable without commenting
