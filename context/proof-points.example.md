# Proof points (example)

Copy to `context/proof-points.md`. Several skills (launch-post, format-radar,
ad-breakdown, x-content-playbook) enforce one rule: **no invented numbers.**
Any performance figure in a post must trace to this file, the demo, or the
user's own words. If a number is not here, the skill leaves a `[slot]`.

## Approved for public use

| Claim | Exact wording allowed | Source | Approved on |
|---|---|---|---|
| Customer result | "2.5 to 4x return on ad spend across the pilot accounts" | pilot dashboard export, 2026-06 | 2026-06-20 |
| Usage | "40,000+ ads generated" | product analytics | 2026-05-01 |

## Requires permission before each use
- Any named customer.
- Any figure more precise than the ranges above.

## Never
- Vendor case-study numbers (agencies selling the format).
- Extrapolations ("would have", "on track to").
- Anything from a screenshot you cannot reproduce.
